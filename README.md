# jlaprocido.github.io

Personal portfolio. Static HTML/CSS/JS, hosted on GitHub Pages.

## Preview locally
`python -m http.server 8000` then open http://localhost:8000

## Update
- New project: copy a `.card` block in `index.html`; put files in `assets/`.
- New resume: overwrite `assets/resume.pdf` (keep the filename).
- Publish: `git add . && git commit -m "update" && git push`
